# Kasa
Repo for the Kasa project from OpenClassrooms' JS-React path.
## Context
The goal of this project was to build a responsive application with ReactJS/React Router/SCSS based on provided Figma mockups.
This was implemented with careful attention to :
- pixel perfect integration
- responsive behavior across screen sizes
- reusable React components

Deployed [here](https://jeanne-v-kasa.netlify.app/)
